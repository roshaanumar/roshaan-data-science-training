# Data Science & AI Internship Training

A portfolio repository collecting my Python, data analysis, machine learning, generative AI, and final-project exercises completed during my internship training (August–September 2026).

## Repository structure

| Folder | Contents |
|---|---|
| [`01-python`](01-python/) | Python fundamentals and JSON exercises |
| [`02-data-analysis`](02-data-analysis/) | Pandas, data cleaning, exploratory analysis, API exercises, and web scraping |
| [`03-machine-learning`](03-machine-learning/) | Introductory ML, model comparison, and customer risk classification |
| [`04-generative-ai`](04-generative-ai/) | LLM exercises, semantic search, RAG, and an agent exercise |
| [`05-final-project`](05-final-project/) | AI Risk Research Assistant prototype and supporting evaluation data |

## Highlights

- Practiced data preprocessing and analysis using Python and Pandas.
- Explored supervised classification models and performance metrics.
- Experimented with text embeddings, semantic similarity, RAG, and LLM workflows.
- Developed an AI risk-research prototype for looking up entities, collecting sources, and summarizing findings.

## Running an exercise

Open the exercise's folder, install the libraries required by the script or notebook, and run it from that folder so local file references resolve. Some AI exercises also require local Ollama models or external API access.

The `customer-risk-classification` folder has its own detailed README and dependency list. The final project's dataset information is documented in `05-final-project/README_batch1.md`.

## Notes

These are educational/prototype exercises, not production screening or decision-making systems. Data and results should not be used to make consequential decisions about real people. Before publishing material from internship work, verify that the content is approved for public sharing.
